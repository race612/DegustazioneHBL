Impostazioni Serata

Configura la scheda di degustazione e genera il link / QR code da dare agli assaggiatori.

Serata

Su Google Drive verrà creato automaticamente il file "Degustazione - [nome serata]" alla prima scheda ricevuta. Usa lo stesso nome per far confluire le schede nello stesso file.
Una per riga: sono le voci del menu "Seleziona la versione".

Loghi

Uno per riga. Puoi anche caricare un'immagine nel repository e indicarne il nome file (es. birrificio.png).

Collegamento Google

L'URL del deployment dello script unico (apps-script/Code.gs). Si imposta una sola volta: viene ricordato su questo dispositivo.
L'URL deve iniziare con https://script.google.com/
